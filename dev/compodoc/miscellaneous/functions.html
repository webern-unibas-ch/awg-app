toConstructQuery
toConstructQuery(query: string)

Utils method: toConstructQuery.

It converts a given SELECT query into the short form of a CONSTRUCT query (CONSTRUCT WHERE { triples }) with the same pattern (case-insensitive). The projection is dropped, solution modifiers (GROUP BY, ORDER BY, LIMIT etc.) are kept. Queries whose pattern is not a plain triples pattern (with FILTER, OPTIONAL etc., nested groups or property paths) are not converted.

Parameters :
Name Type Optional Description
query string No

The given SELECT query.
Returns : string | null

The CONSTRUCT query, or null if the query cannot be converted.
